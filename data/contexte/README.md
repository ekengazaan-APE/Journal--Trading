# Contexte automatique de la Top-down

Un fichier par semaine ISO (`2026-W41.json`), écrit par les tâches programmées « Contexte Top-down »
sur la branche `contexte` depuis le 14/10/2026 (une écriture sur `main` déclenche une mise en ligne Netlify,
qui coûte 15 crédits sur les 300 du plan gratuit). Le journal lit la branche `contexte` sur raw.githubusercontent.com
puis, à défaut, le fichier servi par le site. Les fichiers de ce dossier sur `main` sont l'historique jusqu'au 13/10/2026.
(dimanche vers 17h pour la semaine suivante, jours de semaine vers 13h50 pour la mise à jour).
La page Top-down du journal le lit et l'affiche. Ces tâches n'écrivent jamais dans le journal lui-même.
